# 换人设：把模板改成另一个博主的样子

模板默认是「午休日记」：米白信纸 + 杏橘 + 宋体 + 一小时的时间戳做板块编号。
换成别的博主，**只动四样东西**：时间隐喻、色板、板块命名、装饰元素。结构和排版逻辑不要动。

## 一、换掉时间隐喻

模板的板块编号（`<span class="clock"><b>12:00</b>…</span>`）用的是"一个午休的时间线"。
换人设时，把这个隐喻换成**该博主的一天**或**一次行为**：

| 人设 | 编号主题 | 示例 |
|---|---|---|
| 通勤 / 穿搭 | 早高峰时间线 | 07:20 出门 / 07:45 地铁 / 08:30 到公司 |
| 家居 / 收纳 | 一次整理流程 | ① 清空 ② 分类 ③ 归位 ④ 维持 |
| 母婴 / 育儿 | 娃的一天 | 06:30 起床 / 10:00 遛娃 / 21:00 哄睡 |
| 探店 / 吃喝 | 一顿饭的顺序 | 11:40 排队 / 12:10 上菜 / 13:00 结账 |
| 宠物 | 主子的一天 | 08:00 早饭 / 14:00 午睡 / 22:00 拆家 |
| 健身 / 运动 | 一次训练 | 热身 15′ / 主课 45′ / 拉伸 10′ |

只要编号**读起来像真实生活的一段**就成立。别用"第一章""PART 01"这种方案感太重的写法。
最后一个板块建议留一句收尾台词（模板是"闹钟响了，回去上班"），这是全页情绪落点。

导航里的 `<small>12:15</small>` 要和对应板块的 clock 编号一致。

## 二、换色板

改 `:root` 里的 8 个变量即可，其余全部引用变量：

```css
:root{
  --paper:#fbf6ee;   /* 页面底：带一点暖的纸 */
  --sheet:#fffdf9;   /* 卡片：比底色亮一档 */
  --cream:#f4ebdd;   /* 次级色块 */
  --line:#e8dccb;    /* 虚线/描边 */
  --ink:#2e2723;     /* 正文：暖墨，不用纯黑 */
  --mute:#7b6e64;    /* 次要文字，对比度 4.9:1 */
  --sun:#d9744f;     /* 强调：大字与装饰 */
  --sun-ink:#a9502f; /* 强调深色版：小字用，保证 5:1 */
  --butter:#f7e2a6;  /* 马克笔高亮 */
  --sage:#8fa58a;    /* 对比数据 */
  --sage-soft:#e3eadf;
  --blush:#f6e1d6;
}
```

三套可直接用的替代：

| 人设 | paper / sheet | 强调 sun / sun-ink | 辅色 sage / butter |
|---|---|---|---|
| 家居 · 极简 | `#f7f5f1` / `#fffefb` | `#8a7a63` / `#6b5c47` | `#a8b0a0` / `#ece2cf` |
| 母婴 · 温柔 | `#fdf6f3` / `#fffcfb` | `#e08d94` / `#b8636c` | `#b8cbb4` / `#f9e6c9` |
| 宠物 · 活泼 | `#fbf8ec` / `#fffdf6` | `#e0973f` / `#a86a1f` | `#93b48f` / `#ffe6a8` |

**不要用纯白 `#ffffff` 做底、纯黑 `#000000` 做字。** 米白 + 暖墨是这套页面"纸感"的来源。
强调色只用于：大数字、峰值、标签底色、左边框。整页强调色占面积别超过 5%。

深色版（`--paper:#0b0d0c`、`--ink:#f1f3e9`、`--sun:#d6ff64`）只用于**运动/科技类**博主，
且要用户明确要求。生活类博主一律浅色。

## 三、换板块命名

7 个板块的顺序和职责固定，只换标题措辞：

1. `12:00 开场` → 一句话定位（Hero）
2. `12:15 作品` → 数据最好的 9 条
3. `12:40 数据` → 季度曲线 + 两组比率
4. `13:00 经历` → 我做过的事（成绩单 + 人群 + 总结）
5. `13:20 方法` → 我做内容的 N 条原则
6. `13:40 优势` → 我能带给团队的 N 件事
7. `14:00 关于` → 收尾 + 事实表

第 4 和第 6 最容易写反：**第 4 是"发生了什么"（事实+数字），第 6 是"所以我能干什么"（能力）**。
两者不要重复同一批数字，第 6 的数字要换成"能力口径"（如 90 篇 → 一个人跑通全链路）。

## 四、装饰元素（少而准）

- 拍立得：白边 + 胶带 + `rotate(-1.5deg~1.5deg)`，用 `:nth-child(3n)` 做随机感；只在作品区用
- 账本分隔：`border-bottom:1.5px dashed`，用于成绩单/数据条
- 马克笔高亮：`background:linear-gradient(transparent 62%, var(--butter) 62%)`，一个板块最多一处
- 漂浮动画：模板里的 `Zzz` 换成该人设的符号（咖啡热气、猫爪、音符），`prefers-reduced-motion` 下必须停

## 五、不能动的底线

- 正文对比度 ≥ 4.5:1（大字 ≥ 3:1）；`--mute` 在浅底上不要再调浅
- 触控目标 ≥ 44px；折叠按钮要带 `aria-expanded` 和 `aria-controls`
- `prefers-reduced-motion` 时停掉描线、漂浮、渐显（模板已有，别删）
- 断点只保留 900px（两栏转单栏）和 640px（字号、拍立得缩小）
- 图片一律 base64 内嵌，交付物必须是**能单独发出去的一个 HTML 文件**
